# bclock
### Browser Clock （ブラウザで時計）

ブラウザで時計を表示するだけのページです。<br>
パソコンの待機画面などで、時間を表示するのに使っています。

https://licodeenar.github.io/bclock/  で公開しています。<br>
デフォルトのホーム画面に設定するなどして利用ください。


<img src="/img/og-image.png" >

背景画像は、Pixabyより気に入った画像を選んでいます。<br>
※ 背景画像募集中！


### 機能

- 現在時刻を大きく表示（時：分）
- ランダムな背景画像
- 右上のボタンから操作可能
  - 背景を変える
  - 全画面表示の切替
  - 設定パネルを開く

### 設定

右上の設定ボタン（⚙）から以下の項目を変更できます。設定はブラウザに保存されます。

| 項目 | 内容 |
|------|------|
| フォント | Fira Code / Orbitron / VT323 / Share Tech Mono / Bebas Neue |
| 背景の自動切替 | オフ / 1分 / 3分 / 5分 / 10分 |
| 秒を表示 | 時：分：秒 の表示に切替 |


### 自分で使うとき

index.html と img フォルダをそのままダウンロードすれば、ローカル環境でも動きます。

img フォルダ内に 00 〜 12 の JPG ファイルを配置して、リロードするたびにランダムで背景を変更します。<br>
好きな画像ファイルに差し替えて使ってください。
